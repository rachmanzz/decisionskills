# Security Policy

## Supported versions

Security fixes are provided for the latest `v0.1.x` release. Users should keep the installed skill and its source repository up to date.

## Reporting a vulnerability

Please do not disclose a vulnerability in a public issue or pull request.

Use [GitHub private vulnerability reporting](https://github.com/rachmanzz/decisionskills/security/advisories/new) when available. If private reporting is unavailable, email `rachmanzz.ak@gmail.com` with the subject `Security report: decisionskills`.

Include:

- a clear description of the vulnerability and its impact;
- the affected version, file, or script;
- reliable reproduction steps or a minimal proof of concept;
- any suggested mitigation, if known.

Do not include real credentials, private project data, or other sensitive material in the report. Redact or replace them with safe examples.

The maintainer will acknowledge reports when practical, investigate the issue, and coordinate disclosure after a fix or mitigation is available.
