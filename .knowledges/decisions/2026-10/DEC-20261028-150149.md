# Use append-only decision history for this skill project

## Decision

This project uses timestamped Markdown decision records under .knowledges/decisions/. Existing records are never edited or deleted; changes are recorded as new decisions that may supersede earlier ones.

## Rationale

Durable decisions should remain traceable to support both human review and future AI actions.

## Consequences

- The skill package must teach agents to read relevant decisions before consequential work and to append new records when durable choices are confirmed.

## Agent action

Use the decision-history workflow for project decisions and preserve the full historical chain.
